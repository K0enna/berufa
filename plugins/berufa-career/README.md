# Berufa Career

Nine free career Skills for ChatGPT Work and Codex on desktop. Plugin version
0.1.0 packages the selected-text Skills 0.2.3. This is a publication candidate;
directory approval and publication are separate steps.

Start with setup, or choose advice, content writing, evidence onboarding, role
evaluation, application preparation, interview preparation, offer comparison or
search-outcome review. Describe the result you want. After the sharing explanation
and your agreement, paste only the selected text needed for the task. Missing facts
stay open. Your assistant supplies the model under your account's terms and charges.

The supported inputs are pasted experience notes, posting text, selected drafts,
offer terms and confirmed events. The plugin does not browse, extract attachments,
read ambient files, connect a saved career profile, send applications, or update a
pipeline. A fresh chat needs the selected basis and sharing agreement again.

Complete editable text in chat is the default. Where the host supports it, request
a new Markdown file at an explicit local destination. The Skill must preserve
existing files and verify a new file before claiming delivery. Real-content PDF
and Word output are excluded; the included optional formatter is fictional-only.
The plugin requires desktop execution for its local file workflows. It includes
no MCP server, hooks, provider credentials or model client.

The [sharing profile](references/standalone-profile.md) defines the boundary.
Review the [fictional examples](examples/standalone-workflows.md), then try a role
assessment, requested draft, focused correction and interview practice. Review
outputs for facts, voice and suitability before using them.

Install this complete package through your host's supported local plugin route.
Use the accompanying repository guide for the exact source/build command and
human acceptance steps. Do not treat an archive or discovered Skill as proof of
successful ChatGPT execution. Web, mobile and all-platform behavior are untested.
