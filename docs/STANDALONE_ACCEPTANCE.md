# Berufa Skills 0.2.0: acceptance scope

The selected-text standalone package contains nine career Skills. Each produced a completed
useful output from newly supplied fictional career facts in coordinator-inspected Codex CLI
trials: a starting brief, experience/source summary, role assessment, application brief and
answer, interview material, offer comparison, search review, advice and complete CV.

Eight additional scenarios covered denied sharing, embedded hostile posting instructions,
unsupported connections/browsing/submission, critique without rewriting, resumption without
old facts, exclusive new Markdown with readback, one-sentence editing with surrounding bytes
preserved, and preservation of an existing output. All 17 inspected scenarios passed. The
file answer contained 113 words; a model-generated intermediate regex was not a reliable
word counter, so the coordinator checked the final text independently.

The actual trials used Codex CLI 0.162.0-alpha.17.2 on Windows and GPT-6.1 Sol/high. This names
the tested setup, not a minimum version or instruction to widen permissions. Each Skill was
explicitly selected and read from an isolated installed archive. Automatic menu discovery and
Cursor/Claude Code runtime behavior are not established by these trials. Their setup guidance
uses documented host layouts with shared resources preserved.

The final archive changes only the README, neutral manifest identity and profile opening.
All nine Skill instructions, shared methods, document contract, examples and scenario files
remain byte-identical: 39 unchanged members. The complete sharing, file, action and resumption
boundary below the profile opening is also identical. Manifest closure and every member digest
were independently checked. A final first-use disclosure trial on the exact final ZIP also passed: the Skill explained provider processing and requested agreement without analyzing the supplied facts.

Packaging checks: 42 passed; lint/format passed; nine Skill frontmatter validators and resource
closure passed. Preserved core/workflow suite: 134 passed, one existing host-symlink skip.
Those checks establish their named scope, not all-input model reliability. Users must review
the result, preserve supplied qualification/ownership/currency limits and make their decisions.
No real career facts or credentials were used in these trials. No application or message was sent.

The package supports selected pasted text and requested new editable Markdown. It does not
connect private records, browse, extract attachments, send or schedule. Real-content PDF/Word
delivery is excluded. Model processing remains subject to the user's assistant/provider terms.
Independent GPT-6.1 Sol/high review completed at P0–P2 scope with no actionable findings;
the existing helper's secret scan passed. It covered the stable product candidate and matching
website capability changes. Publication approval remains pending; this report does not publish
or approve a release. Earlier v0.1.2 distribution remains a separate legacy package.
