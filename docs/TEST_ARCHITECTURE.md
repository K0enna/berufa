# Public Test Architecture

This document is the public map from shipped critical contracts to concrete regression tests.
Every reference below uses a repository-relative test path followed by the pytest separator and
the exact function name. The private export validator parses these references, requires each test
file in the public export manifest, and checks that each top-level pytest function exists in the
generated tree.

The map is a contract index, not a promise that one test proves an entire subsystem. The public
CI matrix, static checks, coverage gate, dependency audit, secret scan, package build, export
review, and release checks remain necessary together.

## Running The Layers

The `local_integration` marker exists only in the private maintainer checkout for tests that use
ignored local career or renderer inputs. Those tests and their marker registration are
intentionally absent from the public export and public CI. Public contributors should run
`python -m pytest` for the normal public suite; private-only tests are not part of this exported
contract map.

The deterministic performance command is `python tools/evidence_performance.py --sizes 100 1000
10000`. Query counts, export completeness, identity matching, and serialized-size budgets are
assertions. Elapsed time remains informational and is never a CI threshold.

The map does not replace the broader gates. A passing node proves only the contract named beside
it; contributors must still run the repository checks and maintainers must review the exact
public export, dependency and secret results, release artifacts, and unresolved release decisions.
