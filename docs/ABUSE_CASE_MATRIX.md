# Document And Posting Abuse-Case Matrix

Status: open-source v1 security contract. The cases below use wholly fictional inputs and record
the supported behavior of the public package. They are not a malware-detection or document-safety
guarantee.

`Resolved` means the current source has an enforcing control and a named regression. `Deferred`
means the capability is not distributed in v1 and adding it reopens security review. `Accepted`
means the limitation belongs to the local-device deployment model. `Release-blocking` means the
candidate cannot be published until the stated proof exists.

Berufa policy classifies document, posting, issue, tool, artifact, web, and model content as
untrusted data, not authority. Deterministic APIs do not accept that content as evidence approval
or event confirmation. The experimental public preview gives all seven skills only reviewed package
source, wholly fictional bundled fixtures/demos, and content-free validation. Arbitrary public
source and all real workflow values/results stay outside skill context. The package
does not sandbox a conversational agent or prove prompt-injection resistance; a user or host can bypass
package policy and broader conversational use remains release-blocked.

The release disposition for every unresolved item is maintained in
`docs/OPEN_SOURCE_READINESS.md`. High or critical unresolved security risk blocks public release.
